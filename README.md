# Skirk Marble CN

**Skirk Marble** 的简体中文汉化分支。

用于增强 [wplace.live](https://wplace.live) 的游玩体验：模板管理、准星辅助、地点搜索、信息栏(用户名/水滴/升级经验/充能状态)、瓦片缓存等。

原版由 [Seris0](https://github.com/Seris0/Wplace-SkirkMarble) 开发(MPL-2.0),本分支在原版 v1.0.0 基础上完成全界面汉化,并修复了多个因站点改版导致的失效问题。

**点击[这里](https://github.com/AzulCat7720/Skirk-Marble-CN/releases/download/v1.0.2/SkirkMarble-CN_v1.0.2.user.js)即可安装最新脚本，安装前请确认你已安装[Tampermonkey](https://www.tampermonkey.net/)。**

仅可作辅助工具使用，无自动化等违规功能。

### 主要功能

- **模板管理**：导入/导出/重命名/删除模板、模板进度追踪、错误像素/缺失像素检测与导航、模板截图
- **准星辅助**：可自定义颜色/大小/半径/透明度/边框/增强模式的准星,错误颜色增强
- **地点搜索**：站点内地点搜索 + 收藏夹(本地存储)
- **信息栏**：用户名、水滴数、升级所需像素、充能状态与倒计时
- **其他**：瓦片缓存、迷你进度追踪器、顶部进度条、颜色过滤、错误地图等

## 与原版的差异

### 1. 全界面简体中文汉化

设置面板、地点搜索窗口、收藏夹、模板管理、全部提示(toast)、确认框、排序选项、占位符、悬浮提示均已翻译为简体中文。

**刻意保留英文的部分**:

- 调色板颜色名称(如 `Transparent`、`Dark Slate Blue`)：颜色名称会随设置一起存入本地存储,翻译会导致旧存档显示不一致;
- 控制台调试日志(非界面内容)

### 2. 功能改进

部分原版功能有待优化，或因站点更新无法正常使用，在本汉化版中得以改进，如有问题欢迎反馈。

## 安装与使用

1. 使用 Chrome、Firefox 等浏览器打开本目录下的 `SkirkMarble-CN.user.js`,或在 Tampermonkey 面板中新建脚本并粘贴内容
2. 因 @name 与原版不同,安装后为独立脚本"Skirk Marble CN",**不会覆盖**原版，且**可以与原版共存**（但在实际使用时最好不要同时启用）
3. 启用脚本后刷新 wplace.live 页面即可使用

### 与原版共存注意事项

- 两个脚本可同时在 Tampermonkey 中保留,但 **@match 完全相同,请勿同时启用**——会重复注入两套界面导致冲突
- 用中文版就启用 "Skirk Marble CN" 并停用原版,反之亦然
- 设置数据存储于 `bm*`/`skirk` 前缀的键,两版共用,切换版本时设置自动延续
