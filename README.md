# Skirk Marble CN

**Skirk Marble** 的简体中文汉化分支。
用于增强 [wplace.live](https://wplace.live) 的游玩体验:模板管理、准星辅助、地点搜索、信息栏(用户名/水滴/升级经验/充能状态)、瓦片缓存等。

原版由 [Seris0](https://github.com/Seris0/Wplace-SkirkMarble) 开发(MPL-2.0),本分支在原版 v1.0.0 基础上完成全界面汉化,并修复了多个因站点改版导致的失效问题。

点击[这里](https://github.com/AzulCat7720/Skirk-Marble-CN/blob/main/SkirkMarble-CN.user.js)即可安装脚本，安装前请确认你已安装[Tampermonkey](https://www.tampermonkey.net/)。

### 主要功能

- **模板管理**:导入/导出/重命名/删除模板、模板进度追踪、错误像素/缺失像素检测与导航、模板截图
- **准星辅助**:可自定义颜色/大小/半径/透明度/边框/增强模式的准星,错误颜色增强
- **地点搜索**:站点内地点搜索 + 收藏夹(本地存储)
- **信息栏**:用户名、水滴数、升级所需像素、充能状态与倒计时
- **其他**:瓦片缓存、迷你进度追踪器、顶部进度条、颜色过滤、错误地图等

## 与原版的差异

### 1. 全界面简体中文汉化

设置面板、地点搜索窗口、收藏夹、模板管理、全部提示(toast)、确认框、排序选项、占位符、悬浮提示均已翻译为简体中文。

**刻意保留英文的部分**:

- 调色板颜色名称(如 `Transparent`、`Dark Slate Blue`):颜色名称会随设置一起存入本地存储,翻译会导致旧存档显示不一致;
- 控制台调试日志(非界面内容)

### 2. 移除"飞行到当前坐标"按钮

原版主面板上的 `🗺️` 飞行按钮(读取瓦片/像素坐标转换为经纬度后飞行)无法实现,遂删除；保留"飞行到模板坐标""飞行到此瓦片"等其余飞行入口。

### 3. 主面板标题

主面板标题由 "Skirk Marble" 改为 **"Skirk Marble CN"**,与脚本名一致,便于与原版区分。

## 相较于原版的实现改动(部分功能因Wplace网站更新无法实现，遂尝试修复)

### 1. 飞行功能修复(核心改动)

**原版实现**:`fe(lat, lng, zoom)` 直接调用 `unsafeWindow.bmmap.flyTo(...)`,依赖站点暴露的地图实例全局变量 `window.bmmap`。

**失效原因**:站点前端重构(SvelteKit + MapLibre GL)后移除了 `bmmap` 全局,地图实例深藏于组件内部状态,外部脚本无法再获取;原版自带的"bmmap 猎手"(hook `Map.prototype.values` 探测)也因站点数据结构变化而失效。因此原版与汉化版的飞行动作全部失效。

**汉化版实现**(`fe()` 两级降级):

1. 若 `unsafeWindow.bmmap.flyTo` 存在(站点将来恢复该接口),优先平滑飞行
2. 否则跳转到带坐标的 URL(`/?lat=…&lng=…&zoom=…`),由站点官方定位机制完成导航——保证到达目标位置

所有飞行入口(飞行到模板坐标、飞行到此瓦片、搜索结果、错误/缺失像素飞行)共用此函数,一处修复全局生效。

**已知取舍**:当前"飞行"为整页跳转到达(约 2~3 秒),不是原版的无缝地图动画;这是站点不再暴露地图 API 前提下的可靠方案。若站点恢复地图全局,脚本会自动切回平滑飞行。

### 2. 用户信息获取修复

**原版实现**:注入页面脚本 hook `window.fetch`,把站点所有 JSON 请求响应通过 `postMessage` 转发给主脚本,主脚本按端点末段分发(`case "me"`),填充用户名/水滴/升级经验/充能状态。

**失效原因**:站点用户数据 store 仅在页面启动时请求一次 `/me`(无定时刷新),而 SvelteKit 应用启动早于油猴脚本的 fetch 钩子安装(document-end),首次请求被错过,之后站点不再主动请求 → 信息栏永远停留在"加载中..."。

**汉化版实现**:

- 新增 `@connect backend.wplace.live` 权限
- 新增主动拉取函数:用 `GM_xmlhttpRequest` 直接请求 `https://backend.wplace.live/me`(自动携带登录 Cookie)
- 调度:页面加载 1.2 秒后首次拉取,之后每 60 秒刷新一次,保持数据新鲜
- 兼容处理:自动解包 `{data: …}` 包装结构;未登录时仅提示一次"您尚未登录",不重复打扰
- 原有消息监听机制保留,站点后续如有 `/me` 请求仍可实时更新

### 3. 准星透明度滑块修复

**原版缺陷**:准星半径滑块有自定义轨道样式(6px 高、渐变背景、圆角),而准星透明度滑块只有 `width:100%`,完全依赖浏览器原生渲染——深色面板上原生轨道近乎不可见,看起来像"滑块不见了"。

**修复**:为透明度滑块补上与半径滑块相同的轨道样式(`height:6px`、slate 渐变背景、`border-radius:3px`、`appearance:none`),轨道与缩略图均清晰可见。

### 4. 元数据调整

| 项 | 原版 | 汉化版 | 说明 |
| --- | --- | --- | --- |
| @name | Skirk Marble | Skirk Marble CN | 与 @namespace 组成独立脚本身份,可与原版共存安装 |
| @updateURL / @downloadURL | 有 | 移除 | 防止自动更新把汉化覆盖回英文 |
| @connect | wplace.live / wplace.lol | + backend.wplace.live | 用户信息主动拉取所需 |
| @version | 1.0.0 | 1.0.0-CN | 与更新机制配合 |

## 安装与使用

1. 用 Firefox 打开本目录下的 `SkirkMarble-CN.user.js`,或在 Tampermonkey 面板中新建脚本并粘贴内容
2. 因 @name 与原版不同,安装后为独立脚本"Skirk Marble CN",**不会覆盖**原版，且**可以与原版共存**（但是在实际使用时最好不要这么做）
3. 启用脚本后刷新 wplace.live 页面即可使用

### 与原版共存注意事项

- 两个脚本可同时在 Tampermonkey 中保留,但 **@match 完全相同,请勿同时启用**——会重复注入两套界面导致冲突
- 用中文版就启用 "Skirk Marble CN" 并停用原版,反之亦然
- 设置数据存储于 `bm*`/`skirk` 前缀的键,两版共用,切换版本时设置自动延续

## 已知限制

- **飞行非无缝动画**:当前为整页跳转到达目标位置(见上文实现改动 §1)
- **调色板颜色名保留英文**(见上文功能差异 §1)
- **用户信息每 60 秒轮询刷新**,非实时推送;倒计时基于本地时钟计算,精度足够日常使用
- 站点后续若再次改版(接口/结构变化),部分增强功能可能需要再次适配
